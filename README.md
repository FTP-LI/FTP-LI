## About Me

- 主线方向：嵌入式硬件开发与 MCU 固件开发
- 当前关注：STM32、外设驱动、通信协议和 PCB 设计
- 持续整理：学习代码、工程项目、硬件资料和开发笔记
- 开源目标：让项目具备清晰文档、可复现代码和完整硬件资料
- 内容分享：通过 GitHub、哔哩哔哩和立创开源平台记录开发过程

我喜欢从一个简单的想法开始，经过原理图设计、PCB 制作、固件编写和调试，最终让它真正运行在硬件上。
